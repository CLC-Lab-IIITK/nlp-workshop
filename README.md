# NLP Workshop for MSc Statistics

### CLC Lab
**Culture, Language, Life and Computing**  
Department of Computer Science and Engineering  
Indian Institute of Information Technology Kottayam

---

Hands-on materials for an introductory Natural Language Processing
workshop designed for MSc Statistics students.

## Workshop Topics

1. Introduction to Natural Language Processing
2. Tokenization and Text Processing
3. Word Embeddings
4. N-gram Language Models
5. Text Classification and Sentiment Analysis
6. Transformers and LLM APIs
